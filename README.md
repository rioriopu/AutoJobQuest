# AutoJobQuest

製作8職・採集3職のジョブクエスト（Lv1〜70）を、素材集めから報告まで自動で進める
Dalamud プラグイン。

```
職を選んで「ジョブクエ開始」
  → 事前点検 → 開始の確認（マーケットボードで買う予定の品・ギルの消費）
  → 職ごとに区切って、区切りごとに
      呼び鈴でリテイナーから要る品を引き出す
      → マテリア装着・精選が未解放なら、解放のクエストを進める
      → 足りない素材を集める（マーケットボード・NPC 購入・戦闘・採集・精選・釣り）
      → 未読の秘伝書が要れば、収集品を作って納品 → 紫貨で交換 → 読む
      → グリダニアの宿屋で製作（Artisan）
      → マテリアを付ける
      → ジョブクエを1本ずつ進める（受注・移動・会話・報告は Questionable）
```

持ち物とクエストの進み具合は毎回ゲームから読み直す。止めても、もう一度始めれば続きから進む。

**他のプラグインの本体には手を加えていない。** 公開されている IPC で連携し、IPC で届かないもの
（GBR の採集リスト・NPC 購入リスト・設定など）だけリフレクションで一時的に書き換えて、終わったら戻す。

## 導入

Dalamud の設定（`/xlsettings`）の「試験機能」→「カスタムプラグインリポジトリ」に、次の URL を足して保存する。

```
https://raw.githubusercontent.com/rioriopu/PrivateReleaseRepo/main/repo.json
```

プラグインの一覧（`/xlplugins`）で「AutoJobQuest」を探して入れる。

## 対象

| 区分 | 職 | ジョブクエ |
|---|---|---|
| 製作 | 木工・鍛冶・甲冑・彫金・革細工・裁縫・錬金・調理 | 各19本（Lv1〜60 の15本＋Lv61〜70 の4本） |
| 採集 | 採掘・園芸・漁師 | 各22本 |

- 選ぶ職は、**すでに Lv70 以上**であること（開始条件）。
- 全部終えた職は「完了」と出て、選べない。
- メインクエストは進めない。前提のクエストが未完了のジョブクエがあれば、その手前まで進めて止まる。
  前提がメインクエストなら、最後にその受注の NPC に話しかけ、断られたところで止まる（どこで止まるかは開始の確認に出る）。

## 始める前の条件

### 開始条件（職を選ぶと ✓／✗ で並ぶ。全部 ✓ になるまで開始できない）

| 条件 | 内容 |
|---|---|
| レベル | 選んだ職が Lv70 以上 |
| 装備 | 選んだ製作職のギアセットの主道具・副道具・頭・胴・腕・脚・足が Lv68 以上（アクセサリーと採集職の装備は見ない） |
| 鞄 | 選んだジョブクエに要る空き枠＋予備枠（予備は設定タブで変える。既定 5） |
| メインクエスト | 「いざ山岳地帯へ」をクリア済み（ジョブクエと、マテリア装着・精選・刺突漁の解放に要るもののうち一番先。ゲームデータから求める） |
| 風脈 | 蒼天・紅蓮のエリアの風脈をすべて開放済み |
| エーテライト | 蒼天・紅蓮のフィールドのエーテライトをすべて解放済み（新生のエリアは見ない） |
| 受注数 | 受注中のクエストが、受注枠より2つ少ない数（いまの受注枠30件なら28件）以下 |
| プラグイン | 上の10個が読み込まれている |
| ギル | 選んだ職 × 15万ギル（目安） |

### 事前点検で止まるもの

「ジョブクエ開始」を押すと点検し直し、次のときは始めない。「事前点検」タブの「点検する」で先に見られる。

- Artisan がリスト実行中・連続製作中
- HQ 指定の品があるのに、Artisan の「Use Quick Synthesis where possible」が ON
- HQ 指定の品の HQ の見込みが 100% に届かない（下の「止まる場面・注意」）
- Questionable の「止める条件」に進めるジョブクエが入っている／「クエストを完了しない」（PreventQuestCompletion）が ON
- 推奨装備に着替える手順のあるジョブクエが残っていて、Questionable の着替えがギアセットも上書きする設定（Stylist）になっている
- 使う製作職・選んだ採集職のギアセットが無い
- マテリアを付ける品がアーマリーチェストにある（カバンに移してから始める）

### 用意しておくこと

- **使いたい素材・完成品はリテイナーに預けておく**（開始後に呼び鈴から引き出す）。チョコボかばんの中身は数えず、引き出さない。
- **グリダニアの宿屋に入れること。** 製作は宿屋の個室で行う。近くに呼び鈴が無いときのリテイナーの引き出しも同じ個室で行う。
- 戦闘で集める素材があれば、ギアセットのある戦闘ジョブ（いちばんレベルの高いものを使う）。
- 釣りのエサは万能ルアー。0個なら、釣りの前にリムサ・ロミンサ：下甲板層のよろず屋で5個買う（GBR の NPC 購入）。

## 使い方

1. `/ajq` で画面を開く
2. 進めたい職にチェックを入れる（「全てON」でまとめて入る）
3. 職の下の開始条件が全部 ✓ になったら「ジョブクエ開始」
4. 開始の確認（マーケットボードで自動購入すること・買う予定の品・注意）を読んで「はい」

止めるときは「停止」か `/ajq stop`。止めると、他のプラグインに頼んだことを戻す。
止めた後はボタンが「続きから再開」になり、押すと進み具合をゲームから読み直して続きから進む。

### コマンド

| コマンド | 動作 |
|---|---|
| `/ajq` | 画面の開閉 |
| `/ajq stop` | 止める |

### タブ

| タブ | 中身 |
|---|---|
| 計画 | 「計画を更新」で、残りのジョブクエ・足りない素材と入手手段・製作・マテリア装着の予定を出す |
| 事前点検 | 「点検する」で、開始時と同じ点検の結果を出す |
| 必須プラグイン | 導入の状態とインストール |
| 設定 | 下の「設定」 |
| ご支援 | 開発のご支援（Patreon のページを開く・URL をコピー） |

### キャラクタータブ・デバッグタブ（ふだんは隠れている）

**「計画」タブを 5 回続けてクリックすると出る**（間が 1.5 秒を超えると数え直す。もう一度 5 回で隠れる）。

- キャラクター：プラグインがゲームから読み取った内容（秘伝書・装備の基準など）
- デバッグ：詳しい記録（ログ）をファイルに残すかの切り替え（既定 OFF）、記録の表示・「今の状態を書き出す」・「記録のフォルダを開く」、
  この実行でマーケットに払う合計の確認、
  モンスターを倒して素材を集める（敵ごとの「狙う」・狩り場・後回しを決められ、本番の素材集めの戦闘にも効く）

## 設定

| 項目 | 既定 | 説明 |
|---|---|---|
| 1回の購入額がこれを超えたら確かめる（ギル） | 100,000 | 0 で確かめない |
| 必要な数より多く買う分（余り）の額がこれを超えたら確かめる（ギル） | 100,000 | 大きいまとまりしか出品が無いとき用。0 で確かめない |
| 開始したら、呼び鈴でリテイナーから要る品をまとめて引き出す | ON | 切ると手持ちだけで計画する |
| 予備枠（鞄に残しておく空き・枠） | 5 | この空きを残して入らなければ開始できない |
| HQ 指定の品が NQ になったとき、止めずに作り直す回数 | 0 | 0 はその場で止めてチャットで知らせる |
| 素材集め・製作を立て直す周回の上限の基準 | 3 | 集めても足りない：この数＋2周、作っても足りない：この数＋4周で止める |
| 受注後に作る品（Lv61〜70）が HQ にならなかったとき、何回まで作り直すか | 10 | 材料は NPC からもらい直す。クリスタルはこの回数分を先に用意する |
| 選んでいない製作職も、主道具〜足が Lv68 以上の装備でなければ、中間素材を作らずにマーケットボードで買う | ON | 切るとレシピのレベルに届けば作る |
| 漁師 Lv68 の刺突漁（魚影の大方士）を、GBR と AutoHook で自動で行う | ON | 切ると手で行うよう知らせて待つ |
| ジョブクエの製作で Artisan の既定の食事・薬を使う | OFF | 下の「他のプラグインの設定」 |
| 実行の間、受注中のほかのクエストをジャーナルで非表示にする | OFF | 止まったら元の表示に戻す |

デバッグタブにも3つある：「詳しい記録（ログ）をファイルに残す」（既定 OFF。下の「記録（ログ）」）、
「この実行でマーケットに払う合計がこれを超えたら確かめる（ギル）」（既定 0＝使わない）、
「実行していないときも、ショップ・マーケット等の画面を記録する」（既定 OFF。ファイルに残す設定が ON のときだけ使える）。
ほかに、単価が最近の取引の中央値の 3 倍を超える出品も確かめる（画面では変えられない）。
動作中は設定を変えられない。

### 設定はキャラクターごとに分かれる

選んだ職と設定は、ログインしているキャラクターごとに
`pluginConfigs\AutoJobQuest\characters\<キャラクターの ContentId>.json` へ保存する。
ログインしていない間は変えられない。ゲームを2つ起動しても取り合わない。

ログインの前に使う3つだけは全体で1つ（`pluginConfigs\AutoJobQuest.json`）：
`OpenOnStartup`（ゲーム起動時に画面を開く）・`LogDirectory`（記録の置き場所）・`FileLogging`（詳しい記録をファイルに残すか）。
前の2つは画面からは変えられない。`FileLogging` はデバッグタブで切り替える。

## 他のプラグインの設定を一時的に変えるもの

| プラグイン | 変えるもの | いつ |
|---|---|---|
| GBR | ほかの自動採集リストを無効にし、専用リスト「AutoJobQuest」を使う／NPC 購入リスト「AutoJobQuest」 | 採集・釣り・NPC 購入の間 |
| GBR | 帰宅（GoHomeWhenDone・GoHomeWhenIdle）と自動精選（DoReduce）を OFF、「Use vnavmesh Navigation」「Enable Gathering Window Interaction」を ON | 採集・釣りの間 |
| GBR | 収集品の自動納品を OFF／「Abandon nodes without needed items」を ON | 精選に使う収集品を採る間／隠しの採集物を採る間 |
| GBR | UseAutoHook と「Opt-in to fishing data collection」を ON、「Use AutoHook Global Preset」を OFF（竿）、「Force Walking」を OFF（刺突漁） | 釣りの間 |
| RSR | モードを Henched、範囲攻撃（AoEType）を Off、TargetFreely・IgnoreNonFateInFate を OFF | 戦闘・反撃の間 |
| Artisan | 既定の食事・薬を使わない一時指定 | こちらが頼む製作の間（設定で使うにしたときは変えない） |
| Questionable | 優先リストをそのクエストだけにする | クエストの間 |
| TextAdvance | 外部制御を取る（納品窓の入力を切るなど） | クエストの間 |
| AutoHook | 無効にする／刺突漁のプリセットを取り込む | こちらで動く手順の間／刺突漁の間 |

止めたとき・プラグインの読み込みを解除したときに戻す。GBR・RSR・Artisan とジャーナルの変更は、
ゲームが落ちても控えを設定に残し、次に読み込んだときに戻す。

戻せないものが2つある：

- **AutoHook の刺突漁のプリセットが1つ残る**（消す手段が無いため）。要らなければ AutoHook の画面で消す。
- Questionable の優先リストの「受注のみ」の印。

「Opt-in to fishing data collection」が ON の間は、釣った魚のデータが GBR の外部サーバーへ送られる
（OFF だと GBR は魚が目標にあるだけで止まるため。ON にしたときはチャットで知らせる）。

## 止まる場面・注意

- **マーケットボードで自動購入するのでギルを使う。** 開始の確認に買う予定の品が出る。
  上の確認の額を超えると確認窓が出て、「いいえ」で止まる。付けるマテリアの出品が無ければ止まる。
- 前回の購入の結果が分からないまま止まったときは、次の開始で確かめを求める（自動では買い直さない）。
- **倒されたら止まる。** ログアウトしても止まる。
- **HQ の見込みが 100% 未満なら、製作の前に止まる。** 見込みは Artisan の計算を借り、いまのギアセットの能力値で求める（食事・薬は入れない）。
  リテイナーを使う設定なら、引き出した後にもう一度計算し、まだ作る品が届かなければ素材を集める前に止まる。
  食事・薬を使う設定なら止めない（HQ にならなければ材料を使った後に止まる）。
- HQ 指定の品が NQ になったら、既定ではその場で止まる（設定で作り直す回数を増やせる）。
- 素材集めが「設定の数＋2」周続けて集めきれない・製作が「設定の数＋4」周進まないと止まる。
- 時限の採集点を5分を超えて待つジョブクエは、ほかに進められる職があれば後回しにして、そちらを先に進める。
  クエストの釣りの手順の魚が天気・時間帯の限られた魚で、いま釣れなければマーケットボードで買う。
- 戦闘の見回りでは、近くに他のプレイヤーが来たらその場で止まって待つ（水平 50m 以内で止まり、全員が 70m より離れたら続ける）。
- 攻撃されたら、戦闘ジョブなら RSR で反撃する。製作職・採集職のときは記録だけ残して進める。
- Questionable の手順で Artisan の既製のリストが必ず動くジョブクエがある（手持ちの材料で追加製作する。止められない）。開始の確認に出る。
- vnavmesh の「Stop pathing when stuck」と「Retry pathing after stop」が両方 ON だと、止めた後に遅れて歩き出すことがある（どちらかを OFF に）。

## 記録（ログ）

**既定では、ファイルに記録を残さない。** 不具合を調べるときは、デバッグタブ（「計画」タブを 5 回続けてクリックで出る）の
「詳しい記録（ログ）をファイルに残す」を ON にする。切り替えはすぐ効き、次に起動したときも同じ設定で始まる。
OFF の間はファイルを書かず、記録のフォルダも作らない（デバッグタブの記録の表示と Dalamud のログ（`/xllog`）には、ふだんどおり出る）。

ON の間は、プラグインの設定フォルダ（`pluginConfigs\AutoJobQuest`）の `ログ` フォルダに残す。
`LogDirectory` にフォルダを書くと、そちらに置く（書き込めなければ設定フォルダの `ログ`）。
場所はデバッグタブにも出る。

| ファイル | 中身 |
|---|---|
| `全体_日付_キャラクター名.log` | その日の記録すべて |
| `実行_日時_キャラクター名.log` | 「ジョブクエ開始」から止まるまで |
| `失敗_日時_キャラクター名.md` | 止まったときの状況 |
| `状態_日時_キャラクター名.md` | 「今の状態を書き出す」で作る写し |

ON の間は、実行の間のチャットと、ショップ・マーケットボード・会話などの画面の中身も残す（ほかのプレイヤーの会話と、戦闘のダメージ・効果の行は除く）。
ファイルが大きくなるので、調べ終わったら OFF に戻すとよい。古い記録は自動では消さない。

## ビルド

```
dotnet build -c Release
```

`bin\Release\` に `AutoJobQuest.dll`・manifest（`AutoJobQuest.json`）と依存の DLL
（`LuminaSupplemental.Excel.dll`・`CsvHelper.dll`・`CSVFile.dll`・`Sylvan.Data.Csv.dll`）が出る。
すべてを Dalamud の devPlugins フォルダへ置く。**DLL だけでは一覧に出ない。**
ライセンスの文書（`LICENSE`・`THIRD-PARTY-NOTICES.md`・`licenses\`）も同じ場所に出る（配布する zip にも入る）。

Release でビルドすると、`C:\DevPlugins` がある PC では `C:\DevPlugins\AutoJobQuest\` へ自動で配置する。
別の場所に置きたい場合は、環境変数 `AJQ_DEPLOY_DIR` に配置先を指定する。

```
setx AJQ_DEPLOY_DIR "D:\MyPlugins\AutoJobQuest\"
```

どちらも無ければ配置せずビルドだけを行う。Dalamud API 15（Dalamud.NET.Sdk 15.0.0・.NET 10）。
